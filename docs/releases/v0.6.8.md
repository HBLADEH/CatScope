# CatScope v0.6.8

本次更新重整日志工作台，更新 Logo 与主题配色，并将项目首页调整为中文优先。

## 更新内容

- 日志占据工作台主要区域；顶部选择来源、设备、应用和过滤条件，右侧查看日志详情与问题分析，底部按需打开“构建与运行”。
- 使用新版 Logo 与深蓝、青色配色，支持浅色、深色和跟随系统主题。
- Tag、排除词与 Regex 集中在“更多过滤”，已启用条件可见且可单独清除。
- 问题分析支持临时查看被过滤条件隐藏的关联日志，随后返回原过滤结果；重复选择当前问题可重新定位。
- 构建面板支持调整高度，关闭后再打开保留配置和任务输出；窄窗口会调整详情布局。
- 会话保存失败保留名称和备注；取消另存为保留原保存路径。
- 设备、ADB、外观、语言、工作区和应用更新集中在设置中，连接异常时可从状态栏快速打开设备与 ADB 设置。
- 默认 README 改为中文，保留独立英文说明，补齐开源协作、架构和安装文档。

## 安装与升级

- **Windows 10 / 11（x64）**：下载 `CatScope-v0.6.8-windows-amd64.exe` 后直接运行，需要 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。已有 v0.6.6 或更新版本的用户，可在“设置 → 应用更新”中检查更新并安装重启。
- **macOS（Intel / Apple Silicon）**：下载 `CatScope-v0.6.8-macos-universal.dmg`，打开后将 CatScope 拖入 Applications。
- 实时 Logcat 需要本机 Android SDK Platform Tools，以及已开启 USB 调试并授权的设备或模拟器；可在“设置 → 设备”中手动选择 ADB。
- 离线日志与 `.catscope-session` 可以直接打开，无需 ADB 或设备。

## 已知限制

- macOS 仍为 universal preview，尚未完成 Apple notarization，首次打开可能被 Gatekeeper 拦截；确认下载来源后可在“系统设置 → 隐私与安全性”中允许打开。
- macOS 需要手动安装更新；Windows 应用内更新需要 EXE 所在目录可写。
- 暂无官方 Linux 发行包；构建功能的 module 与 variant 选择仍较基础。
- 问题分析使用本地规则，AI Context 只生成本地 Markdown，不上传日志或调用外部模型 API。

## 文件校验

每个安装文件均附带同名 `.sha256` 文件。下载后在文件所在目录校验：

Windows PowerShell：

```powershell
Get-FileHash .\CatScope-v0.6.8-windows-amd64.exe -Algorithm SHA256
Get-Content .\CatScope-v0.6.8-windows-amd64.exe.sha256
```

确认两处 SHA256 值一致（忽略大小写）。macOS：

```sh
shasum -a 256 -c CatScope-v0.6.8-macos-universal.dmg.sha256
```

Release workflow 构建 Windows EXE 与 macOS universal DMG，并检查版本一致性、macOS 双架构和产物校验值。
