# CatScope v0.6.7

本次补丁修复日志量较大或窗口较窄时，日志列表文字重叠的问题。

## 修复

- 保留已测量的日志行高度，避免持续接收日志时，多行消息与后续行重叠。
- 按日志 ID 关联虚拟列表的行高缓存，避免缓冲区满后淘汰旧日志造成位置错乱。
- 日志达到 100000 条后，仍能自动跟随最新日志；保留多行预览和完整日志详情。

## 安装与升级

- Windows 10 / 11：下载 `CatScope-v0.6.7-windows-amd64.exe` 后运行，需要 Microsoft WebView2 Runtime。已有 v0.6.6 的用户可以在“应用更新”中检查更新并安装重启。
- macOS：下载 `CatScope-v0.6.7-macos-universal.dmg`，打开后将 CatScope 拖入 Applications；支持 Intel Mac 和 Apple Silicon。
- 实时 Logcat 需要本机 ADB 和已授权的 Android 设备或模拟器。

## 已知限制

- macOS 仍为 universal preview，尚未完成 Apple notarization，首次打开可能被 Gatekeeper 拦截；确认下载来源后可在系统“隐私与安全性”中允许打开。
- macOS 需要手动安装更新；Windows 应用内更新需要 EXE 所在目录可写。

## 验证与校验

- 本地已验证窄窗口、持续追加及 100000 条缓冲区满载场景。
- Release workflow 分别构建 Windows EXE 和 macOS universal DMG，并验证产物。
- 两个平台均提供同名 `.sha256` 文件。Windows 使用 `Get-FileHash <文件名> -Algorithm SHA256`；macOS 使用 `shasum -a 256 -c CatScope-v0.6.7-macos-universal.dmg.sha256`。
